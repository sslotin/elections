# Монитор блокчейна

`monitor.py` подключается к наблюдателям блокчейна, сохраняет сырые блоки и сразу печатает по одной строке на блок. `search-transaction.py` ищет транзакцию в сохранённых файлах.

## Запуск

Нужен Python 3.10+ и пакет `requests`:

```bash
python -m pip install requests
```

Из этой директории:

```bash
cd monitor
python monitor.py
```

Монитор работает постоянно и проверяет новые блоки каждые 30 секунд. Остановить его можно через `Ctrl+C`. Для одного прохода до текущей высоты:

```bash
python monitor.py --once
```

Строки блоков идут в stdout, сообщения о подключении и сохранении — в stderr. Поэтому их можно разделить:

```bash
python monitor.py > blocks.log
```

Пример строки:

```text
height=123 shard=shard-1 timestamp=2026-09-18T10:15:03.421+03:00 transactions=4 kinds=blindSigIssue:2,vote:2
```

Время выводится по Москве (GMT+3). Для каждого вызова операции смарт-контракта используется её имя (`vote`, `blindSigIssue`, `results` и т. п.); прочие транзакции обозначаются как `type-N`.

## Файлы и возобновление

По умолчанию данные сохраняются в `block-monitor/` относительно текущей директории:

```text
block-monitor/
├── manifest.json
├── shard-0/
│   ├── 000000001-000000100.jsonl
│   └── state.json
└── shard-1/
    └── ...
```

Файлы `.jsonl` содержат исходные блоки, по одному JSON-объекту на строку. Новый chunk сначала пишется во временный файл и только потом получает окончательное имя. `state.json` хранит высоту, до которой данные сохранены.

После остановки достаточно снова запустить ту же команду: уже сохранённые chunks будут пропущены. Не редактируйте их вручную и не запускайте два монитора одновременно с одним `--output-dir`.

Другой каталог можно указать явно:

```bash
python monitor.py --output-dir /path/to/block-monitor
```

Полезные параметры:

- `--chunk-size N` — число блоков в одном chunk (по умолчанию 100);
- `--poll-seconds N` — интервал проверки новых блоков;
- `--only-shard shard-0` — мониторить только один shard;
- `--nodes shard-0=HOST1,HOST2` — заменить адреса наблюдателей для shard;
- `--port N` — HTTP-порт наблюдателей (по умолчанию 6862).

Если адреса сети отличаются от зашитых в скрипте, укажите их через `--nodes`.

## Поиск транзакции

Например, найти транзакцию голосования:

```bash
python search-transaction.py \
  CRCFzVSjz5GWFCdE9vx7Ah7qoYNkG6BDTyE8wytLGvUf \
  --input-dir block-monitor
```

Скрипт напечатает файл и строку, shard, высоту и время блока, вид операции и полный JSON найденной транзакции. Код возврата `0` означает, что транзакция найдена, `1` — что нет.

Если запускать скрипт из каталога `parser`, путь будет таким:

```bash
python monitor/search-transaction.py ID --input-dir block-monitor
```
