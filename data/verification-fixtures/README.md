JSON — известный ответ для хэша первого доказательства расшифровки: домен,
публичные части транскрипта и скаляр вызова CSP. Секретных ключей и случайностей
доказывающего в нём нет. Это контрольный ответ прежней диагностики, а не новая
независимая сертификация CSP. Воспроизвести именно снятие трассы только этим
репозиторием нельзя: диагностический перехватчик здесь не поставляется.

Проверка хэшей файлов, подписей, доказательств и итогов из корня репозитория:

```sh
cd feddeg/verification/opensource
python3 -B -m unittest discover -s tests -v
python3 -B bench.py --no-plot --repeats 100
```

Контрольные итоги: `[[1, 0]]` и `[[4, 0, 0, 0, 0, 0]]`. Тесты меняют только копии
в памяти или временных каталогах. Для восстановления файлов возьмите исходные
выгрузки этих двух контрактов из архива портала и сравните SHA-256; повторное
сжатие CSV может изменить хэш ZIP. Проверка совместимости не доказывает
подлинность, полноту выгрузки или корректность исполнения блокчейна.
